## Вычисленные интегралы

### 1. Задание 1 (Базовый интеграл):
$$I = \int_0^1 e^x dx = e - 1 \approx 1.718281828459$$
*(Дополнительно рассчитан $I = \int_0^{\pi/2} \sin(x) dx = 1.0$)*

Методы:
- Геометрический метод (*Hit-or-Miss*, $M = e$)
- Выборочное среднее (*Sample Mean*, базовая дисперсия $s^2 \approx 0.242$)
- Антитетические переменные (*Antithetic Variates*, снижение дисперсии в **31 раз**)
- Контрольные переменные (*Control Variates*, снижение дисперсии в **60 раз**)
- Расслоенная выборка (*Stratified Sampling*, снижение дисперсии более чем в **9000 раз**)

### 2. Задание 2 (Интеграл из Лабораторной работы №5, Вариант 7):
$$I = \int_0^{\sqrt{3}} \sqrt{3 - x^2} dx = \frac{3\pi}{4} \approx 2.356194490192$$
**Почему выбран именно этот интеграл:**
- Геометрически это площадь четверти круга радиуса $R = \sqrt{3}$ (классическая задача оценки числа $\pi$ методом Монте-Карло).
- В Лабораторной работе №5 вертикальная производная функции при $x \to \sqrt{3}$ ($f'(x) \to -\infty$) привела к потере гладкости: порядок формулы Симпсона упал с теоретического $O(h^4)$ до фактического $O(h^{1.5})$.
- В методе Монте-Карло для сходимости требуется лишь конечность дисперсии ($\int f^2 dx < \infty$). Сингулярность производной не оказывает никакого негативного влияния, и метод демонстрирует стабильную сходимость со скоростью $O(N^{-1/2})$.
