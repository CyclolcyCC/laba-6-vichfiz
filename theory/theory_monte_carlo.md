## А) Теоретические вопросы

### 1. Задачи, решаемые методом Монте-Карло (ММК)

Метод Монте-Карло (метод статистических испытаний) — численный метод решения математических и физических задач, основанный на моделировании случайных величин и статистической оценке их характеристик.

Исторически метод был разработан в конце 1940-х годов Станиславом Уламом, Джоном фон Нейманом и Николасом Метрополисом в Лос-Аламосской национальной лаборатории в рамках Манхэттенского проекта для расчета диффузии нейтронов в делящихся материалах.

Все задачи, решаемые ММК, делятся на два принципиальных класса:

#### 1. Стохастические задачи (естественно-вероятностные процессы)
В этих задачах физический процесс сам по себе подчиняется законам теории вероятностей и квантовой механики. ММК выступает как прямое численное моделирование физической реальности:
- **Перенос нейтронов и гамма-квантов:** моделирование траекторий частиц в активных зонах ядерных реакторов, биологической защите, детекторах элементарных частиц (пакеты GEANT4, MCNP).
- **Физическая кинетика и статистическая физика:** метод Монте-Карло в каноническом и большом каноническом ансамблях (алгоритм Метрополиса — Гастингса, модель Изинга, фазовые переходы, расчет термодинамических потенциалов).
- **Радиационный перенос и оптика мутных сред:** рассеяние света в атмосфере, океане, биологических тканях.
- **Теория массового обслуживания и надежности:** расчет вероятности отказа сложных технических систем, пропускной способности телекоммуникационных сетей.
- **Финансовая математика:** оценка стоимости многофакторных производных финансовых инструментов (опционов), расчет рисков портфелей (VaR).

#### 2. Детерминированные задачи (математический анализ и математическая физика)
В этих задачах исходная постановка не содержит случайности, однако задача искусственно эквивалентно сводится к вычислению математического ожидания некоторой случайной величины:
- **Вычисление многомерных определенных интегралов:** интегралы высокой размерности ($d \ge 4 \dots 100$), где сеточные методы неприменимы из-за комбинаторного взрыва.
- **Решение систем линейных алгебраических уравнений (СЛАУ):** метод случайных блужданий по цепочке узлов (марковские цепи) для нахождения компонент вектора $x = (I - A)^{-1} f$, в том числе вычисление отдельных компонент огромных разреженных матриц без их полного обращения.
- **Краевые задачи для дифференциальных уравнений в частных производных (ДУЧП):** решение задачи Дирихле для уравнения Лапласа/Пуассона $\Delta u = 0$ методом «блуждания по сферам» (Walk-on-Spheres) или блуждания по решетке, основанное на связи оператора Лапласа с винеровским процессом (формула Фейнмана — Каца).
- **Глобальная оптимизация:** поиск глобальных экстремумов многомерных невыпуклых функций со сложным рельефом (метод имитации отжига — Simulated Annealing).

### 2. Основные особенности метода Монте-Карло

1. **Статистическая природа результата:**  
   Результат вычисления не является точным аналитическим числом — это выборочная реализация случайной величины $\bar{\theta}_N$. Результат всегда сопровождается доверительным интервалом, отражающим статистическую погрешность при заданном уровне значимости $\alpha$.

2. **Скорость сходимости $O(N^{-1/2})$:**  
   Согласно Центральной предельной теореме (ЦПТ), среднеквадратичная погрешность метода убывает обратно пропорционально квадратному корню из числа испытаний $N$:
   $$\varepsilon_N \approx \frac{\sigma}{\sqrt{N}}$$
   где $\sigma$ — стандартное отклонение случайной величины. Чтобы увеличить точность на один десятичный знак (уменьшить погрешность в 10 раз), необходимо увеличить объем выборки $N$ в **100 раз**.

3. **Независимость скорости сходимости от размерности пространства $d$:**  
   Это главное преимущество ММК над сеточными методами. В то время как порядок погрешности сеточных формул Ньютона — Котеса равен $O(N^{-p/d})$ (где $p$ — алгебраический порядок точности одномерной формулы), погрешность ММК составляет $O(N^{-1/2})$ при любой размерности $d = 1, 2, 10, 100$. При $d > 2p$ метод Монте-Карло априори превосходит сеточные методы по скорости сходимости.

4. **Инвариантность к геометрической сложности области интегрирования:**  
   Для вычисления интеграла по области сложной формы $\Omega \subset \mathbb{R}^d$ методу Монте-Карло требуется лишь простой алгоритмический предикат `is_inside(point)`. Не требуется триангуляция, построение конформных сеток или аналитическая параметризация криволинейных границ.

5. **Внутренняя апостериорная оценка погрешности «на лету»:**  
   В отличие от сеточных методов, где для правила Рунге требуется полный пересчет интеграла на сгущенной сетке $h/2$, в ММК оценка дисперсии $s^2$ накапливается в том же самом цикле генерации точек без дополнительных затрат памяти и времени.

6. **Критическая зависимость от датчика псевдослучайных чисел (ГПСЧ):**  
   Качество результатов напрямую зависит от свойств генератора (период, отсутствие корреляций между соседними числами, равномерность распределения в гиперкубе $[0,1]^d$). Простые линейные конгруэнтные генераторы (LCCG типа `rand()`) непригодны для серьезных расчетов из-за эффекта Марсальи (концентрация точек на гиперплоскостях). Стандартом являются вихрь Мерсенна (`std::mt19937_64`) или современные датчики семейства PCG/Xoshiro.

### 3. Общая схема метода Монте-Карло

Общий алгоритм реализации ММК для детерминированной задачи состоит из 4 базовых этапов:

```
[Постановка задачи: I] 
       │
       ▼
[Построение вероятностной модели: I = E[ξ]]
       │
       ▼
[Генерация N независимых реализаций ξ₁, ξ₂, ..., ξₙ]
       │
       ▼
[Статистическая обработка: x̄ = Σξᵢ/N, s² = Var(ξ), Доверительный интервал]
```

#### Этап 1. Построение вероятностной модели
Искомая математическая величина $I$ представляется в виде математического ожидания некоторой функции $g(\vec{X})$ от случайного вектора $\vec{X}$, подчиняющегося плотности вероятности $p(\vec{x})$:
$$I = \mathbb{E}[\xi] = \int_{\Omega} g(\vec{x}) p(\vec{x}) d\vec{x}, \quad \text{где } \xi = g(\vec{X}),\ \vec{X} \sim p(\vec{x})$$

#### Этап 2. Моделирование случайных величин
Для генерации случайных векторов $\vec{X}$ с плотностью $p(\vec{x})$ из базовых равномерно распределенных величин $U \sim \mathcal{U}(0,1)$ используются методы:
1. **Метод обратной функции распределения (Inverse Transform Sampling):**  
   Если $F(x) = \int_{-\infty}^x p(t)dt$ — функция распределения, то случайная величина $X = F^{-1}(U)$ имеет плотность $p(x)$.
2. **Метод исключения (метод фон Неймана, Rejection Sampling):**  
   Для плотности $p(x) \le M q(x)$ генерируются $X \sim q(x)$ и $U \sim \mathcal{U}(0,1)$. Если $U \le \frac{p(X)}{M q(X)}$, точка принимается, иначе отбрасывается.
3. **Специальные формулы (например, преобразование Бокса — Мюллера для гауссовых величин).**

#### Этап 3. Проведение независимых испытаний
Генерируется выборка объема $N$: $\xi_1, \xi_2, \dots, \xi_N$, где каждое $\xi_i = g(\vec{X}_i)$. Испытания проводятся независимо, что гарантирует независимость и одинаковую распределенность (i.i.d.) величин $\xi_i$.

#### Этап 4. Статистическая обработка и доверительные интервалы
По закону больших чисел (в форме Хинчина / Колмогорова) выборочное среднее сходится по вероятности и почти наверное к математическому ожиданию:
$$\bar{\xi}_N = \frac{1}{N} \sum_{i=1}^N \xi_i \xrightarrow[N \to \infty]{\text{п.н.}} \mathbb{E}[\xi] = I$$

Несмещенная выборочная дисперсия оценивается как:
$$s^2 = \frac{1}{N - 1} \sum_{i=1}^N (\xi_i - \bar{\xi}_N)^2 = \frac{1}{N - 1} \left( \sum_{i=1}^N \xi_i^2 - \frac{1}{N} \left( \sum_{i=1}^N \xi_i \right)^2 \right)$$

Дисперсия самого выборочного среднего $\bar{\xi}_N$:
$$\mathrm{Var}(\bar{\xi}_N) = \frac{\mathrm{Var}(\xi)}{N} \approx \frac{s^2}{N}, \quad S_{\bar{\xi}} = \frac{s}{\sqrt{N}}$$

По **Центральной предельной теореме**, при $N \to \infty$ нормированная сумма имеет стандартное нормальное распределение:
$$\frac{\bar{\xi}_N - I}{s / \sqrt{N}} \xrightarrow{d} \mathcal{N}(0, 1)$$

Следовательно, с доверительной вероятностью $\gamma = 1 - \alpha$ истинное значение интеграла лежит в интервале:
$$I \in \left[ \bar{\xi}_N - z_{1 - \alpha/2} \frac{s}{\sqrt{N}}, \quad \bar{\xi}_N + z_{1 - \alpha/2} \frac{s}{\sqrt{N}} \right]$$
- Для доверительной вероятности $95\%$ ($\alpha = 0.05$): $z_{0.975} \approx 1.960$.
- Для правила трех сигм ($99.73\%$): $z \approx 3.000$, предельная абсолютная погрешность $\varepsilon_{99.7\%} = 3 \frac{s}{\sqrt{N}}$.

### 4. Вычисление определенных интегралов и методы понижения дисперсии

Рассматривается задача вычисления определенного интеграла:
$$I = \int_a^b f(x) dx$$

#### А. Простейшие методы вычисления

##### 1. Геометрический метод (метод попаданий и промахов / Hit-or-Miss)
Пусть $0 \le f(x) \le M$ на $[a,b]$. Поместим подграфик функции в прямоугольник $D = [a,b] \times [0, M]$ площадью $S_D = M(b-a)$.
Генерируются независимые случайные точки $(X_i, Y_i)$, где $X_i \sim \mathcal{U}(a,b)$, $Y_i \sim \mathcal{U}(0,M)$.
Индикатор попадания точки под кривую:
$$\chi_i = \begin{cases} 1, & Y_i \le f(X_i) \\ 0, & Y_i > f(X_i) \end{cases}$$
Вероятность попадания равна отношению площадей: $p = \frac{I}{S_D}$.
Оценка интеграла:
$$I_{geom} = S_D \cdot \frac{N_{hit}}{N}, \quad \text{где } N_{hit} = \sum_{i=1}^N \chi_i$$
Величина $\chi_i$ подчиняется распределению Бернулли с дисперсией $\mathrm{Var}(\chi) = p(1-p)$.
Дисперсия оценки интеграла:
$$\sigma^2_{geom} = S_D^2 \cdot \frac{p(1-p)}{N} = \frac{I(S_D - I)}{N}$$

##### 2. Метод выборочного среднего (Sample Mean Monte Carlo)
Перепишем интеграл через плотность равномерного распределения $p(x) = \frac{1}{b-a}$ на $[a,b]$:
$$I = (b-a) \int_a^b f(x) \frac{1}{b-a} dx = (b-a) \mathbb{E}[f(X)], \quad \text{где } X \sim \mathcal{U}(a,b)$$
Оценка метода выборочного среднего:
$$I_{mean} = \frac{b-a}{N} \sum_{i=1}^N f(X_i), \quad X_i = a + (b-a) U_i,\ U_i \sim \mathcal{U}(0,1)$$
Дисперсия оценки:
$$\mathrm{Var}(I_{mean}) = \frac{(b-a)^2}{N} \mathrm{Var}(f(X)) = \frac{(b-a)}{N} \int_a^b f^2(x) dx - \frac{I^2}{N}$$

> **Теорема о превосходстве метода выборочного среднего:**  
> Для любой неотрицательной ограниченной функции $0 \le f(x) \le M$ дисперсия метода выборочного среднего строго меньше дисперсии геометрического метода:
> $$\sigma^2_{mean} \le \sigma^2_{geom}$$
> *Доказательство:*
> $$\sigma^2_{geom} - \sigma^2_{mean} = \frac{1}{N} \left[ I \cdot M(b-a) - I^2 - (b-a)\int_a^b f^2(x)dx + I^2 \right] = \frac{b-a}{N} \int_a^b f(x) \big(M - f(x)\big) dx \ge 0$$
> Поскольку $0 \le f(x) \le M$, подынтегральное выражение $f(x)(M - f(x)) \ge 0$ всюду на $[a,b]$, равенство достигается только для кусочно-постоянной функции $f(x) \in \{0, M\}$. Следовательно, геометрический метод всегда проигрывает по эффективности методу выборочного среднего.

#### Б. Способы понижения дисперсии (Variance Reduction Techniques)

Погрешность ММК пропорциональна $\frac{\sigma}{\sqrt{N}}$. Увеличивать $N$ вычислительно дорого ($N \sim \varepsilon^{-2}$). Единственный путь радикального повышения точности — искусственное уменьшение теоретической дисперсии $\sigma^2$.

##### 1. Выборка по важности (Importance Sampling)
Пусть $g(x)$ — вспомогательная плотность вероятности на $[a,b]$, причем $g(x) > 0$ всюду, где $f(x) \ne 0$, и $\int_a^b g(x) dx = 1$.
Тождественно преобразуем интеграл:
$$I = \int_a^b \frac{f(x)}{g(x)} g(x) dx = \mathbb{E}_g \left[ \frac{f(Y)}{g(Y)} \right], \quad \text{где } Y \sim g(x)$$
Оценка:
$$I_{IS} = \frac{1}{N} \sum_{i=1}^N \frac{f(Y_i)}{g(Y_i)}$$
Дисперсия этой оценки:
$$\mathrm{Var}\left(\frac{f(Y)}{g(Y)}\right) = \int_a^b \frac{f^2(x)}{g(x)} dx - I^2$$
*Теорема об оптимальной плотности:* Дисперсия обращается в точный нуль ($\sigma^2 = 0$), если выбрать:
$$g^*(x) = \frac{|f(x)|}{\int_a^b |f(t)| dt} = \frac{f(x)}{I} \quad (\text{для } f(x) \ge 0)$$
Хотя точный знаменатель $I$ нам неизвестен, на практике выбирают функцию $g(x) \propto \tilde{f}(x)$, качественно повторяющую форму $f(x)$ (например, усеченное линейное, параболическое или экспоненциальное распределение), моделируемую аналитически методом обратной функции. Это снижает дисперсию в десятки и сотни раз.

##### 2. Метод противоположных (антитетических) переменных (Antithetic Variates)
Основан на свойстве отрицательной ковариации. Если случайная величина $U \sim \mathcal{U}(0,1)$, то величина $1 - U$ также распределена строго $\mathcal{U}(0,1)$.
Вместо $N$ независимых точек сгенерируем $N/2$ пар взаимно скоррелированных точек:
$$X_i^{(1)} = a + (b-a) U_i, \quad X_i^{(2)} = a + (b-a) (1 - U_i)$$
Элементарная оценка на одну пару:
$$\theta_i = \frac{b-a}{2} \left[ f(X_i^{(1)}) + f(X_i^{(2)}) \right]$$
Дисперсия полусуммы:
$$\mathrm{Var}(\theta) = \frac{(b-a)^2}{4} \left[ \mathrm{Var}(f(X^{(1)})) + \mathrm{Var}(f(X^{(2)})) + 2\,\mathrm{Cov}\big(f(X^{(1)}), f(X^{(2)})\big) \right]$$
Так как $X^{(1)}$ и $X^{(2)}$ одинаково распределены:
$$\mathrm{Var}(\theta) = \frac{(b-a)^2}{2} \mathrm{Var}(f(X)) + \frac{(b-a)^2}{2} \mathrm{Cov}\big(f(U), f(1-U)\big)$$
*Теорема:* Если функция $f(x)$ монотонна на $[a,b]$, то случайные величины $f(U)$ и $f(1-U)$ имеют разное направление монотонности по $U$, поэтому их ковариация строго отрицательна:
$$\mathrm{Cov}\big(f(U), f(1-U)\big) < 0$$
Отрицательная ковариация частично гасит собственные дисперсии слагаемых. При этом метод антитетических переменных не требует вычисления дополнительных интегралов и предельно прост в программной реализации.

##### 3. Метод контрольных переменных (Control Variates)
Пусть известна простая вспомогательная функция $h(x)$ (например, ряд Тейлора, полином интерполяции), которая близка к $f(x)$, но интегрируется аналитически:
$$I_h = \int_a^b h(x) dx \quad \text{— вычислено точно}$$
Тогда интеграл представляется как:
$$I = \int_a^b h(x) dx + \int_a^b [f(x) - h(x)] dx = I_h + (b-a) \mathbb{E}[f(X) - h(X)]$$
Оценка методом Монте-Карло применяется только к остаточной функции $\Delta(x) = f(x) - h(x)$:
$$I_{CV} = I_h + \frac{b-a}{N} \sum_{i=1}^N \big[ f(X_i) - h(X_i) \big]$$
Дисперсия оценки равна:
$$\mathrm{Var}(f(X) - h(X)) = \mathrm{Var}(f) + \mathrm{Var}(h) - 2\,\mathrm{Cov}(f, h)$$
Если $h(x)$ хорошо аппроксимирует $f(x)$, то коэффициент корреляции $\rho(f,h) \approx 1$, и дисперсия остатка $\Delta(x)$ стремится к нулю.

##### 4. Расслоенная выборка (Stratified Sampling)
Отрезок $[a,b]$ разбивается на $K$ равных непересекающихся подынтервалов $[x_{k-1}, x_k]$, на каждом из которых генерируется $n_k = N / K$ точек.
По теореме о разложении дисперсии (закон полной дисперсии):
$$\mathrm{Var}_{total} = \mathbb{E}[\mathrm{Var}(f|k)] + \mathrm{Var}(\mathbb{E}[f|k])$$
Расслоенная выборка полностью устраняет межгрупповую дисперсию $\mathrm{Var}(\mathbb{E}[f|k])$, оставляя только внутригрупповые случайные флуктуации. Исключается эффект случайной кластеризации точек.

## Б) Аналитический расчет практических заданий лабораторной работы №6

### Задание 1.1: Вычисление интеграла $I = \int_0^1 e^x dx$

#### 1. Аналитическое значение
$$I = \int_0^1 e^x dx = \Big[ e^x \Big]_0^1 = e^1 - e^0 = e - 1 \approx 1.718281828459045$$

#### 2. Метод выборочного среднего (Sample Mean)
Случайная величина $X \sim \mathcal{U}(0,1)$, $f(X) = e^X$.
$$\mathbb{E}[f(X)] = \int_0^1 e^x dx = e - 1 \approx 1.718282$$
$$\mathbb{E}[f^2(X)] = \int_0^1 (e^x)^2 dx = \int_0^1 e^{2x} dx = \left[ \frac{e^{2x}}{2} \right]_0^1 = \frac{e^2 - 1}{2} \approx \frac{7.389056 - 1}{2} = 3.194528$$
Теоретическая дисперсия:
$$\sigma^2_{mean} = \mathbb{E}[f^2] - (\mathbb{E}[f])^2 = \frac{e^2 - 1}{2} - (e - 1)^2 = \frac{-e^2 + 4e - 3}{2} \approx 0.242036$$
Стандартное отклонение:
$$\sigma_{mean} = \sqrt{0.242036} \approx 0.491971$$

#### 3. Геометрический метод (Hit-or-Miss)
Прямоугольник: $x \in [0,1]$, $y \in [0, M]$, где $M = e^1 = e \approx 2.718282$.
Площадь прямоугольника $S = M \cdot 1 = e$.
Вероятность попадания $p = \frac{I}{S} = \frac{e - 1}{e} = 1 - e^{-1} \approx 0.632121$.
Дисперсия оценки геометрического метода:
$$\sigma^2_{geom} = I(S - I) = (e - 1)(e - (e - 1)) = e - 1 \approx 1.718282$$
Отношение дисперсий:
$$\frac{\sigma^2_{geom}}{\sigma^2_{mean}} = \frac{1.718282}{0.242036} \approx 7.10$$
*Геометрический метод дает дисперсию более чем в 7 раз выше, чем выборочное среднее!*

#### 4. Понижение дисперсии: Антитетические переменные
Пара точек: $X^{(1)} = U$, $X^{(2)} = 1 - U$.
Оценка на пару: $\theta = \frac{e^U + e^{1-U}}{2}$.
$$\mathbb{E}[\theta] = e - 1$$
$$\mathbb{E}[\theta^2] = \frac{1}{4} \mathbb{E}\big[ e^{2U} + 2e + e^{2(1-U)} \big] = \frac{1}{4} \left( 2 \cdot \frac{e^2 - 1}{2} + 2e \right) = \frac{e^2 + 2e - 1}{4} \approx \frac{7.389056 + 5.436564 - 1}{4} = 2.956405$$
Дисперсия антитетической оценки:
$$\sigma^2_{anti} = \mathbb{E}[\theta^2] - (\mathbb{E}[\theta])^2 = 2.956405 - (1.718282)^2 = 2.956405 - 2.952512 \approx 0.003893$$
Выигрыш по дисперсии:
$$\frac{\sigma^2_{mean}}{\sigma^2_{anti}} = \frac{0.242036}{0.003893} \approx 62.17$$
*Дисперсия снижается в 62 раза! Для достижения той же точности требуется в 62 раза меньше вычислений.*

#### 5. Понижение дисперсии: Контрольная переменная
Возьмем линейную аппроксимацию Тейлора: $h_1(x) = 1 + x$.
$$I_{h_1} = \int_0^1 (1 + x) dx = 1.5$$
Остаточная величина: $\Delta(x) = e^x - (1 + x)$.
$$\mathrm{Var}(\Delta(X)) \approx 0.043640 \quad (\text{снижение дисперсии в } 5.55 \text{ раз})$$
Если взять двухточечную интерполяцию концов отрезка $h_2(x) = 1 + (e - 1)x$:
$$I_{h_2} = 1 + \frac{e - 1}{2} = \frac{e + 1}{2} \approx 1.859141$$
$$\mathrm{Var}(e^X - h_2(X)) \approx 0.004012 \quad (\text{снижение дисперсии в } 60.3 \text{ раз})$$

### Задание 1.2: Вычисление интеграла $I = \int_0^{\pi/2} \sin(x) dx$

#### 2. Метод выборочного среднего (Sample Mean)
Отрезок $[a, b] = [0, \pi/2]$, длина $b - a = \pi/2$.
Точки $X \sim \mathcal{U}(0, \pi/2)$, $X = \frac{\pi}{2} U$, где $U \sim \mathcal{U}(0,1)$.
Оценка: $\xi = \frac{\pi}{2} \sin(X)$.
$$\mathbb{E}[\xi] = \frac{\pi}{2} \cdot \frac{2}{\pi} \int_0^{\pi/2} \sin(x) dx = 1.0$$
$$\mathbb{E}[\xi^2] = \left(\frac{\pi}{2}\right)^2 \mathbb{E}[\sin^2(X)] = \left(\frac{\pi}{2}\right)^2 \cdot \frac{2}{\pi} \int_0^{\pi/2} \sin^2(x) dx = \frac{\pi}{2} \int_0^{\pi/2} \frac{1 - \cos(2x)}{2} dx = \frac{\pi}{2} \cdot \frac{\pi}{4} = \frac{\pi^2}{8} \approx 1.233701$$
Теоретическая дисперсия:
$$\sigma^2_{mean} = \mathbb{E}[\xi^2] - (\mathbb{E}[\xi])^2 = \frac{\pi^2}{8} - 1.0^2 = \frac{\pi^2 - 8}{8} \approx 0.233701$$
Стандартное отклонение:
$$\sigma_{mean} = \sqrt{0.233701} \approx 0.483426$$

#### 3. Геометрический метод (Hit-or-Miss)
$M = \max \sin(x) = 1.0$.
Площадь ограничивающего прямоугольника $S = 1.0 \cdot \frac{\pi}{2} = \frac{\pi}{2} \approx 1.570796$.
Вероятность попадания: $p = \frac{I}{S} = \frac{1}{\pi/2} = \frac{2}{\pi} \approx 0.636620$.
Дисперсия оценки геометрического метода:
$$\sigma^2_{geom} = I(S - I) = 1 \cdot \left(\frac{\pi}{2} - 1\right) = \frac{\pi - 2}{2} \approx 0.570796$$
Отношение дисперсий:
$$\frac{\sigma^2_{geom}}{\sigma^2_{mean}} = \frac{0.570796}{0.233701} \approx 2.44$$

#### 4. Понижение дисперсии: Антитетические переменные
Случайные узлы: $X^{(1)} = \frac{\pi}{2} U$, $X^{(2)} = \frac{\pi}{2} (1 - U)$.

Дисперсия антитетической оценки:

Выигрыш по дисперсии:

*Дисперсия снижается почти в 25 раз!*

#### 5. Понижение дисперсии: Контрольная переменная
1. **Линейная функция** $h_1(x) = \frac{2}{\pi} x$:
   $$I_{h_1} = \int_0^{\pi/2} \frac{2}{\pi} x dx = \frac{\pi}{4} \approx 0.785398$$

### 1D-интегрирование: победа классических квадратур

В одномерном пространстве ($d=1$) для гладких функций метод Монте-Карло **совершенно неконкурентоспособен** по сравнению с квадратурами Ньютона — Котеса и Гаусса:
- Чтобы найти интеграл $I_2 = \int_0^{3\pi/4} x \sin(2x/3)dx = 2.25$ с точностью $\varepsilon = 10^{-6}$:
  - **Формуле Симпсона** достаточно $N \approx 40$ вычислений функции (доли микросекунды).
  - **Методу Монте-Карло** потребуется $N \approx \left(\frac{3 \cdot 1.78}{10^{-6}}\right)^2 \approx 2.8 \times 10^{13}$ вычислений функции (несколько часов счета на процессоре).
- Применение методов понижения дисперсии (антитетические переменные, контрольные переменные) уменьшает константу при $N^{-1/2}$ в 10–50 раз, но **не меняет степенной показатель сходимости $-1/2$**.

### Многомерный случай ($d \ge 4$): проклятие размерности

Почему же тогда метод Монте-Карло является фундаментальным инструментом вычислительной математики? Ответ — **многомерные интегралы**.

Пусть интеграл вычисляется в $d$-мерном кубе $[0,1]^d$:
$$I = \int_{[0,1]^d} f(x_1, x_2, \dots, x_d) \, dx_1 \dots dx_d$$

1. **Сеточные методы (тензорное произведение квадратур):**  
   Если по каждому измерению взять $m$ узлов (шаг $h = 1/m$), то суммарное число узлов равно $N = m^d$, откуда шаг $h = N^{-1/d}$.
   Погрешность формулы Симпсона:
   $$\varepsilon_{Simpson} = O(h^4) = O(N^{-4/d})$$
   Погрешность формулы трапеций:
   $$\varepsilon_{Trapezoid} = O(h^2) = O(N^{-2/d})$$

2. **Метод Монте-Карло:**  
   Погрешность:
   $$\varepsilon_{MC} = O(N^{-1/2}) \quad \text{при любом } d$$

Сравним показатели степени при $N$:
- При $d = 1$: Симпсон $N^{-4} \gg N^{-1/2}$ (Симпсон быстрее).
- При $d = 4$: Трапеции $N^{-2/4} = N^{-1/2}$ (трапеции сравнялись с Монте-Карло).
- При $d = 8$: Симпсон $N^{-4/8} = N^{-1/2}$ (Симпсон сравнялся с Монте-Карло).
- При $d > 8$: Симпсон сходится **медленнее**, чем простейший метод Монте-Карло!
- При $d = 20$: Для сетки всего по $m = 10$ точек по каждой координате требуется $N = 10^{20}$ вычислений функции (невозможно выполнить за сотни лет на всех суперкомпьютерах мира). Метод Монте-Карло легко вычисляет этот интеграл с точностью $1\%$ при $N = 10^6$ точек за секунду.

### Влияние гладкости функции (урок Варианта 7)

В лабораторной работе №5 для Интеграла 1 Варианта 7:
$$I_1 = \int_0^{\sqrt{3}} \sqrt{3-x^2} dx$$
наблюдался принципиальный эффект:
- Производная подынтегральной функции $f'(x) = -\frac{x}{\sqrt{3-x^2}} \to -\infty$ при $x \to \sqrt{3}$.
- Теорема о погрешности формулы Симпсона $R_n \le \frac{(b-a)^5}{2880} \max |f^{(4)}(\xi)| h^4$ требует непрерывности 4-й производной. Из-за сингулярности производной фактический порядок сходимости формулы Симпсона в лабе 5 упал с $O(h^4)$ до **$O(h^{1.5})$**, а экстраполяция Ричардсона давала сбои.
- **Для метода Монте-Карло производные функции не имеют никакого значения!** Единственное условие сходимости по ЦПТ — конечность интеграла от квадрата функции:
  $$\int_0^{\sqrt{3}} (\sqrt{3-x^2})^2 dx = \int_0^{\sqrt{3}} (3 - x^2) dx = 2\sqrt{3} < \infty$$
  Поскольку дисперсия конечна ($\sigma^2 \approx 0.448$), ММК сходится с безупречной скоростью $O(N^{-1/2})$ без каких-либо аномалий и замедлений.

### Способ контроля погрешности (Рунге vs ЦПТ)

| Характеристика | Лаб 5 (Правило Рунге и Ричардсон) | Лаб 6 (Статистический доверительный интервал) |
| :--- | :--- | :--- |
| **Формула оценки** | $\varepsilon_{Runge} = \frac{I_{h/2} - I_h}{2^p - 1}$ | $\varepsilon = z_{1-\alpha/2} \frac{s}{\sqrt{N}}$ |
| **Затраты вычислений** | Требует пересчета интеграла на второй (удвоенной) сетке | Получается бесплатно в процессе накопления $\sum \xi_i$ и $\sum \xi_i^2$ |
| **Природа погрешности** | Детерминированная асимптотическая оценка главного члена ошибки | Вероятностная гарантия (с надежностью $95\%$ или $99.7\%$) |
| **Возможность экстраполяции** | Ричардсон позволяет исключить главный член ошибки $I^{(1)} = \frac{2^p I_{h/2} - I_h}{2^p - 1}$ | В ММК экстраполяция невозможна, но дисперсия снижается аналитическими приемами |

### Параллелизуемость и вычислительная сложность

Метод Монте-Карло относится к классу задач с естественным параллелизмом (**«embarrassingly parallel»**):
- Каждое случайное испытание абсолютно автономно и не зависит от предыдущих.
- Чтобы ускорить расчет в $P$ раз на многоядерном процессоре или GPU, достаточно раздать потокам генерацию $N/P$ точек с независимыми начальными состояниями ГПСЧ (разные `seed` или jump-ahead смещения).
- В квадратурах Ньютона — Котеса параллелизация требует согласования границ отрезков и сбора узлов сетки, а при адаптивном шаге — динамической балансировки нагрузки между потоками.

## Д) Практические рекомендации к программной реализации

### 1. Архитектура генератора псевдослучайных чисел
Используйте современный стандартный генератор C++:
```cpp
#include <random>

// Инициализация аппаратным энтропийным источником
std::random_device rd;
std::mt19937_64 rng(rd()); // 64-битный вихрь Мерсенна
std::uniform_real_distribution<double> dist01(0.0, 1.0);
```

### 2. Численно устойчивое вычисление среднего и дисперсии «на лету» (Алгоритм Велфорда)
Прямое вычисление дисперсии по формуле $\sum x_i^2 - \frac{1}{N}(\sum x_i)^2$ при больших $N$ ($10^7 - 10^8$) подвержено катастрофической потере точности из-за вычитания близких больших чисел с плавающей точкой (catastrophic cancellation).

Рекомендуется использовать однопроходный алгоритм Велфорда (Welford's algorithm):
```cpp
struct MonteCarloAccumulator {
    uint64_t count = 0;
    double mean = 0.0;
    double M2 = 0.0; // Сумма квадратов отклонений

    void update(double x) {
        count++;
        double delta = x - mean;
        mean += delta / count;
        double delta2 = x - mean;
        M2 += delta * delta2;
    }

    double get_mean() const { return mean; }
    double get_variance() const { return count > 1 ? M2 / (count - 1) : 0.0; }
    double get_std_error() const { return std::sqrt(get_variance() / count); }
    double get_margin_95() const { return 1.95996 * get_std_error(); }
    double get_margin_997() const { return 3.00000 * get_std_error(); }
};
```

### 3. Схема вызова для интегралов задания
```cpp
// 1. Метод выборочного среднего для exp(x) на [0, 1]
double u = dist01(rng);
double val_raw = std::exp(u);

// 2. Метод антитетических переменных для exp(x)
double u = dist01(rng);
double val_anti = 0.5 * (std::exp(u) + std::exp(1.0 - u));

// 3. Метод контрольной переменной: h(x) = 1 + (e - 1)*x, I_h = (e + 1)/2
double u = dist01(rng);
double h = 1.0 + (std::numbers::e - 1.0) * u;
double val_cv = (std::numbers::e + 1.0) / 2.0 + (std::exp(u) - h);
```

## Резюме

1. **Метод Монте-Карло** — универсальный вероятностный аппарат, незаменимый для многомерных задач ($d \ge 4$), задач с нерегулярной геометрией и физического стохастического моделирования.
2. В одномерных задачах со гладкими функциями он значительно уступает по скорости квадратурам **Ньютона — Котеса** (Лаб №5).
3. При наличии корневых особенностей производных (как в Варианте 7: $\sqrt{3-x^2}$) метод Монте-Карло сохраняет свою устойчивую скорость сходимости $O(N^{-1/2})$, тогда как метод Симпсона деградирует.
4. Применение **методов понижения дисперсии** (антитетических переменных, контрольных переменных, выборки по важности) позволяет сократить дисперсию в **10–250 раз**, превращая ММК в высокоэффективный расчетный инструмент.
